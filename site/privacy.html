Privacy statement

OSflux sends nothing anywhere.

OSflux and OSflux Studio make no network connections, send no data and have no telemetry. This program will not transfer any information to other networked systems unless you ask it to.

What OSflux reads

  • The image file you choose, such as a Windows or Linux ISO.
  • The drives on your PC: their model, size, serial number and how they are connected, to tell which ones may be written. With Administrator rights it also reads a removable drive's partition table and top folder, to see whether it is empty.
  • For the Windows Setup option that copies this PC's region and keyboard, your formats, locale and keyboard layout, which go only onto the stick you write.

What OSflux keeps

Only on your PC, in %LOCALAPPDATA%\OSflux:

  • audit.log: every confirmation and write, with the time, your Windows user and computer name, the image's path, size and SHA-256, and the drive's path, model and identity code.
  • The one-time write confirmations, each removed once used and useless after 10 minutes.
  • OSflux Studio's settings (theme and verify after writing) and its log of how it started.

You can read or delete these files at any time. The folder can be moved with the OSFLUX_STATE_DIR environment variable.

Links

The Website, Source code and Report a problem links in OSflux Studio's About open in your browser, which then follows its own privacy settings. OSflux itself does not connect.

This website

This site has no trackers, cookies or JavaScript, and its fonts are served from the site itself. It is hosted on GitHub Pages, which may keep server logs as described in GitHub's privacy statement.
